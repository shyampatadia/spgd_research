1. INITIAL EXPECTATIONS  (from proposal.tex / PROJECT_PLAN.txt)
================================================================================

Stated hypothesis (proposal section 3 / 4):
  H1. Standard optimizers (SGD/Adam) stall near saddle points; SPGD's
      steepest-perturbation rule should escape them faster than vanilla
      perturbation (PGD) and faster than random selection (RPGD).
  H2. The selection rule -- not perturbation alone -- is what matters.
      Operationally: SPGD > RPGD on test accuracy AND/OR stagnation episodes.
  H3. ResNet-18 with batch-norm DISABLED in [layer1, layer2] preserves
      enough saddle structure for the saddle-escape mechanism to matter.

Acceptance criteria (PROJECT_PLAN.txt section 4):
  AC1. ResNet-18 SGD baseline reaches >= 0.90 test accuracy at 50 epochs.
  AC2. All 15 jobs complete on Turing without crashing.

Compute estimate from proposal:
  ~2 hours per run on RTX 4050  ->  ~30 GPU-hours total.

Diagnostic of interest:
  Stagnation episodes = consecutive minibatch steps with ||grad|| < 1e-3.
  Non-zero counts indicate plateau/saddle traversal; SPGD is expected to
  show fewer or shorter episodes than SGD/Adam.

Risk register hits relevant here (PROJECT_PLAN section 5):
  R2. ResNet-18 + SPGD may diverge if amp too large       -> monitor
  R5. 3 seeds is small; report mean +/- std AND paired    -> applied below

The five optimizers all start from the same model parameters when given the
same seed, so paired (per-seed) deltas are the most powerful comparison
available with only 3 seeds.

seed | SPGD test acc | RPGD test acc | SPGD - RPGD | SGD test acc | SPGD - SGD
-----+---------------+---------------+-------------+--------------+-----------
 0   |    0.8487     |    0.8045     |   +0.0442   |    0.8491    |  -0.0004
 1   |    0.8379     |    0.8265     |   +0.0114   |    0.8159    |  +0.0220
 2   |    0.7964     |    0.7387     |   +0.0577   |    0.8154    |  -0.0190
mean |               |               |   +0.0378   |              |  +0.0009

Interpretation:
  - SPGD beats RPGD on ALL 3 seeds (mean +3.78 percentage points).
    This is consistent with hypothesis H2: the steepest-selection rule
    contributes meaningful signal beyond random perturbation.
  - SPGD ties SGD overall (mean +0.09 pp): the perturbation mechanism
    does not help relative to vanilla SGD when there are no plateaus
    to escape (see findings below).
  - The SPGD>RPGD gap is the cleanest evidence in this experiment that
    *selection* matters; without that comparison one would conclude
    perturbation is harmful (PGD/RPGD < SGD).

6. FINDINGS vs INITIAL EXPECTATIONS
================================================================================

[F1]  ZERO STAGNATION EPISODES across all 15 runs.   (NULL on saddle hypothesis)
      Expected: SGD/Adam show non-zero stagnation; SPGD shows fewer.
      Observed: nobody hits ||grad|| < 1e-3 for any consecutive window.
      Likely cause: ResNet-18 with BN disabled only in {layer1, layer2}
      still has BN in {layer3, layer4} + 2x downsample shortcuts.  These
      surviving normalization paths keep gradient magnitudes well above
      the 1e-3 threshold.  CIFAR-10's loss landscape, even with this
      handicap, is too well-conditioned at lr=1e-2 for plateau traversal
      to be observable at this granularity.
      Implication for the report: state this explicitly.  The proposal's
      "preserve saddle structure" intervention was insufficient.  Either
      (a) lower stagnation_eps to ~1e-2, (b) disable BN globally, or
      (c) switch to a network/dataset where saddles are known to dominate.

[F2]  SPGD's SELECTION RULE TRANSFERS TO REAL DATA.        (supports H2)
      SPGD - RPGD = +3.78 pp test accuracy, paired across all 3 seeds.
      This mirrors Exp 1 (d=10 Ackley) where SPGD-vs-random showed a clear
      mean improvement, and Exp 3 OpenML where the same pattern held on
      tabular data.  CIFAR-10 + ResNet-18 is the largest-scale evidence
      we have that selection >= random perturbation, even when there are
      no overt saddles to escape.

[F3]  PERTURBATION ALONE HURTS ON THIS LANDSCAPE.          (informs Discussion)
      PGD (mean acc 0.809) and RPGD (mean 0.790) are BOTH below SGD
      (mean 0.827).  Adding noise to a smooth, fast-converging landscape
      degrades the optimizer.  SPGD partially recovers because the
      selection rule rejects bad candidates; RPGD has no such filter.

[F4]  ADAM IS THE STRONGEST OPTIMIZER HERE.                (expected)
      Mean test accuracy 0.9015 -- the only optimizer to clear AC1 = 0.90.
      With Kaiming initialization and no momentum on the others, Adam's
      adaptive per-parameter step size dominates.  This does NOT
      contradict H1/H2 -- the proposal's claim is about saddle escape,
      not asymptotic accuracy on a saddle-free landscape.

[F5]  ACCEPTANCE CRITERION AC1 NOT MET FOR SGD.           (caveat to discuss)
      SGD: 0.8268 (target was >= 0.90).
      Reason: the proposal-mandated handicaps -- no momentum on SGD/PGD/
      RPGD/SPGD, BN disabled in early layers -- intentionally sacrifice
      asymptotic accuracy to preserve saddle structure (which then
      didn't show up; see F1).  The handicaps work as designed for the
      controlled comparison; they just shift the absolute-accuracy bar.

[F6]  COMPUTE BUDGET BEAT THE ESTIMATE BY ~16x.            (good news)
      Estimated   : ~2 h per run on RTX 4050  -> ~30 GPU-h total.
      Actual A30  : ~7.6 min per run          -> ~1.9 GPU-h total.
      With 2 A30s in parallel + 5-minute pre-emption gaps between array
      tasks, the entire 15-run sweep finished in 64 minutes wall-clock.

================================================================================
9. ONE-LINE SUMMARY FOR THE REPORT ABSTRACT
================================================================================
On CIFAR-10 / ResNet-18 (BN disabled in early stages, 50 epochs, 3 seeds),
SPGD beat the same-mechanism random-selection baseline (RPGD) by 3.78 pp test
accuracy paired across all seeds, supporting the claim that the steepest
candidate rule contributes meaningful signal; however, no optimizer recorded
a single stagnation episode (||grad|| < 1e-3), so the saddle-escape mechanism
the proposal targeted did not measurably engage on this landscape, and Adam's
adaptive step (mean acc 0.9015) outperformed all gradient+perturbation methods.
